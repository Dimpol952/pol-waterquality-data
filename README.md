# pol-waterquality-data

Αποτελέσματα ελέγχων ποιότητας πόσιμου νερού για τον Δήμο Πολυγύρου σε μορφή JSON (ανοικτά δεδομένα).

## Το αρχείο

`water_quality_all.json` — ένας πίνακας με τα σημεία δειγματοληψίας του Δήμου. Κάθε σημείο έχει:

| Πεδίο | Περιεχόμενο |
|---|---|
| `id` | Κωδικός σημείου δειγματοληψίας |
| `area`, `point`, `address` | Περιοχή, ονομασία και διεύθυνση του σημείου |
| `waterZone` | Ζώνη ύδρευσης |
| `longitude`, `latitude` | Συντεταγμένες (WGS84) |
| `longitudeEgsa87`, `latitudeEgsa87` | Συντεταγμένες (ΕΓΣΑ87) |
| `measurements` | Οι πιο πρόσφατες αναλύσεις του σημείου |

Κάθε εγγραφή στο `measurements` είναι μία μέτρηση. Τα βασικά πεδία της: `chemIndex` (παράμετρος), `value` και `valueStr` (τιμή), `samplingDate` (ημερομηνία δειγματοληψίας), `analysisDate` (ημερομηνία ανάλυσης), `lab` (εργαστήριο), `acceptable` (αν η τιμή είναι εντός ορίων).

## Πηγή και ενημέρωση

- Πηγή: η πλατφόρμα παρακολούθησης ποιότητας νερού της ΕΔΕΥΑ, https://ydor.edeya.gr
- Ενημερώνεται αυτόματα την 1η ημέρα κάθε μήνα στις 09:00 (ώρα Ελλάδας).
- Το αρχείο αντικαθίσταται ολόκληρο σε κάθε ενημέρωση και είναι σε συμπαγή μορφή (χωρίς κενά), για μικρότερο μέγεθος.

## Χρήση

Απευθείας σύνδεσμος στο αρχείο:
`https://raw.githubusercontent.com/Dimpol952/pol-waterquality-data/main/water_quality_all.json`

Τα δεδομένα δημοσιεύονται όπως παρέχονται από την πηγή. Για επίσημη ενημέρωση σχετικά με την ποιότητα του νερού ισχύουν οι ανακοινώσεις του Δήμου.
